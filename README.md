# COVID-19 Global Data Exploration — SQL

## Project Overview
Exploratory data analysis of global COVID-19 data using MySQL — 
analysing infection rates, death percentages, and vaccination 
rollout across 200+ countries.

## Tools & Skills
- MySQL — JOINs, CTEs, Window Functions, Aggregate Functions
- Data Source: Our World in Data

## Key Business Insights
- Identified countries with highest infection rates vs population
- Calculated rolling vaccination rates using Window Functions
- Compared death percentages across continents
